# Day 22｜持久化队列与 worker / 锁、租约与任务回收

日期：**2026-09-29**（计划学习日期）  
周次：第 4 周 · 可靠执行与 MCP  
学习单元：原计划 Day 43 + Day 44

## 单元 1：持久化队列与 worker

- 任务提交与执行分离，API 返回运行标识，worker 从持久化队列领取作业。
- 网页关闭和 API 重启不应自动丢失已接受任务。

## 单元 2：锁、租约与任务回收

- 锁防止正常情况下并发领取，租约允许失联任务被回收。
- 旧 worker 恢复时可能与新 worker 竞争，写入还需要所有权检查或防重复机制。
