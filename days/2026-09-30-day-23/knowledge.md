# Day 23｜外部 API 与最小权限 / 批准后执行真实写入

日期：**2026-09-30**（计划学习日期）  
周次：第 4 周 · 可靠执行与 MCP  
学习单元：原计划 Day 45 + Day 46

## 单元 1：外部 API 与最小权限

- 认证、分页、限流和错误格式都是工具接口的一部分。
- 凭据由服务端保管，允许操作的仓库或资源范围由程序限制。

## 单元 2：批准后执行真实写入

- 计划、审批和工具操作记录需要关联，远端 ID 应被持久化。
- 先校验授权再执行，不能由模型自行声明批准。
