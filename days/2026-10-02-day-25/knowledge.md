# Day 25｜模块复盘：故障恢复 / MCP 的角色与基本能力

日期：**2026-10-02**（计划学习日期）  
周次：第 4 周 · 可靠执行与 MCP  
学习单元：原计划 Day 49 + Day 50

## 单元 1：模块复盘：故障恢复

- 可靠性证据来自故障实验，而不只来自一次顺利演示。
- 需要说明故障发生的位置、已确认事实和仍然未知的结果。

## 单元 2：MCP 的角色与基本能力

- MCP 描述 Host、Client、Server 的协作与工具等能力交换。
- 协议不决定 Agent 的业务目标，也不天然授予访问权限。
